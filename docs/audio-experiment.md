# 音频获取验证

这是开发验证记录，尚未接入插件的一键音频获取或说话人分离功能。

## 已验证

视频：`BV1728bzzEwA`，P3，`cid=31308972765`，时长 393 秒。

- 页面播放数据提供独立 DASH 音轨，编码为 AAC（`mp4a.40.2`）。
- 使用当前可访问音轨的地址发出 HTTP Range 请求，服务器返回 `206 Partial Content`。
- 完整音轨大小为 3,121,284 字节，本次仅下载开头 524,288 字节。
- 用本机 FFmpeg 从部分音频中生成两个 WAV：源 00:00–00:05、00:10–00:25。
- 输出为 16 kHz、单声道、16-bit PCM；已检查解码、时长和非静音。

下载范围记录见 [download-metadata.json](../fixtures/audio/download-metadata.json)，样本验证见 [verification.json](../fixtures/audio/verification.json)。音频二进制保留在本机忽略的 `artifacts/audio/`，不提交到 Git。
