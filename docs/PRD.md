# B站逐字稿侧栏｜0.5.0 ASR PRD

## 1. 目标与范围

在 B站普通视频页面，通过用户主动确认的百炼 ASR 转写原始音频，在 Chrome / Edge 原生侧栏阅读、回看、播放高亮和导出。保留原话、完整 ASR 句子、匿名 speaker 和时间映射；不读取平台字幕、不补标点、不摘要改写、不使用大模型分段。

- 支持用户有权访问的视频及分 P，不绕过登录、付费或访问限制。
- 百炼 API key 是生成新稿的前提；无 key 可读已有本地文稿。
- DeepSeek 独立可选，仅用于姓名/角色推断；未配置或推断失败不影响基础稿。
- 打开侧栏、切换视频、刷新和读取缓存不自动发起付费调用。

## 2. 交互要求

| 功能 | 要求 |
| --- | --- |
| 原生侧栏 | 工具栏图标打开浏览器 Side Panel，不覆盖或修改视频页布局；宽度和开合由浏览器管理。 |
| 配置 | 工具栏右键“设置”打开独立页，分别保存百炼和 DeepSeek 密钥、模型；不内置或回显密钥。 |
| 主动转写 | 点击“转写音频”，确认完整音频及头像截图上传和收费提示后开始；展示下载、上传、提交、等待进度，支持本地取消。 |
| 基础稿 | ASR 返回后立即按 speaker 和完整句子生成本地规则段落，无需 DeepSeek。 |
| 人物推断 | 自动将标题、简介、分 P 标题、UP主公开资料及完整转写发送至 DeepSeek；只接受能在上下文原文校验的姓名/角色，同一具体姓名不重复分配给多个 speaker。证据不足保持未知，失败可重试。 |
| 头像 | 自动选取少量视频帧上传百炼视觉模型，优先按姓名匹配，其次使用本人发言回合的单人特写；低置信或失败使用数字/姓名首字占位。 |
| 播放 | 点击正文句子跳到对应 ASR 句起点并播放；点击段落时间戳保留播放/暂停状态；拖选复制不跳转。 |
| 高亮与跟随 | 按真实播放时间更新当前句及段落；手动滚动或选字暂停跟随，可恢复，高亮仍更新。 |
| 保存与导出 | 本地保存原始 ASR、句子、段落、人物和偏好；支持 Markdown 导出，刷新仅读缓存。 |

人物推断不是声纹识别或身份认证；姓名依据可悬停查看。未知者显示“未知发言人＋编号”。人物及头像后处理失败必须保留已生成稿件。

## 3. ASR 数据契约

主流程位于 [app.js](../extension/app.js)：

`读取原始 audio → transcribeAudio → normalizeTranscript → paragraphize`

原始 M4A 直接下载并上传百炼，不转码、不以短片段代替正式输入。默认模型 `qwen-audio-3.1-asr-flash-filetrans`，异步任务启用说话人分离，选择 `channel_id: [0]`。先持久化 task ID，再轮询并获取原始结果。

[transcript.js](../extension/transcript.js)读取 `transcripts[].sentences`，保留原文、毫秒起止时间、speaker ID 及 words，按时间排序后生成连续句子 ID。缺失 speaker 标为未知，不猜身份。完整 ASR 句子不可拆分，words 不强拆为阅读句，不插值逐字时间，重复、口头语和识别错误原样保留。

基础分段按连续 speaker 回合处理；speaker 变化为硬边界，不跨说话人合段。默认 `targetChars = 250`，选择完整句间接近目标的边界。200～300 字是阅读目标而非强制区间；短问答可独立成段，长句可超过目标，无 350 字或其他硬上限。段落正文由原句直接拼接，时间和来源由句子推导。

## 4. 缓存、取消与隔离

- 文稿键：`asr-document:v1:<bvid>:<cid>`，按视频及分 P 隔离。
- 任务键：`asr-task:v1:<bvid>:<cid>:<model>`，保存任务 ID 和已完成原始结果，不持久化上传凭据或临时资源 URL。
- 人物推断缓存须包含实际文字、上下文、模型及提示词身份，不能仅按视频名复用；旧平台字幕缓存不是 ASR 文稿。

取消停止本地等待和后续处理，不声称云任务已取消或不会收费。再次主动转写可续接同模型已提交 task，避免重复下载、上传和提交；失败后重新提交可能再次收费。重新转写须主动确认，刷新不得清空稿件后自动转写。

切换标签页、视频或分 P 立即隔离旧稿、取消本地旧处理并忽略迟到结果；只控制当前活动标签页的视频。网络、鉴权、无有效语音和缓存错误分别提供可操作提示，失败保留已有稿件和可续接任务。

## 6. 隐私与非目标

主动确认后百炼接收原始音频及少量头像截图，DeepSeek 接收发言人推断所需文字与公开上下文。密钥只存本机扩展存储，不进入桥接、源码、日志或发行包；不读取或导出 B站 Cookie。真实密钥、私有配置、缓存、原始音视频和生成报告不得进入公开仓库。

不承诺 ASR 纠错、逐字时间精度、speaker 准确率或真实身份识别。不做摘要、翻译、直播、其他平台和账号云同步。

## 7. 验收

1. 运行时只走原始音频 ASR，无平台字幕或大模型分段路径；未确认不提交任务。
2. 无百炼 key 无法生成新稿，已有缓存可读；无 DeepSeek key 基础稿完整可用。
3. 250 字目标、speaker 硬边界、整句不拆、原文和时间不变；长句不会因超长失败。
4. task key 含模型；取消后可主动续接，失败和跨标签页/视频/分 P 切换不覆盖已有文稿。
5. 正文点击播放、时间戳保留状态、拖选复制、高亮、暂停/恢复跟随和 Markdown 导出可用。
6. 覆盖缓存恢复、下载/上传/提交/轮询失败、无有效语音、人物/头像失败、取消和上下文切换；敏感数据不进入发布内容。

[脱敏 ASR 样例](../fixtures/README.md)来自约 29 分钟圆桌音频的一次实测：168 句、5 个 speaker、50 个基础段落。不能据此保证其他声道或重复识别相同，说话人准确率未经人工听校。离线测试、样例渲染和真实播放器跳转联调不能替代安装后权限、CDN 下载及云上传实机验收。
