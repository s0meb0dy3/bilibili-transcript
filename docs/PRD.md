# B站逐字稿侧栏｜0.4.8 ASR PRD

## 1. 产品目标与范围

在 B站普通视频页面，通过用户主动确认的百炼 ASR 转写原始音频，生成带匿名说话人、完整句子及时间映射的段落逐字稿。在 Chrome / Edge 原生侧栏中阅读、回看、播放高亮与导出；可选使用 DeepSeek 优化自然段边界，不以摘要或改写替代原话。

- 支持当前用户可访问的视频及分 P，不绕过登录、付费或访问限制。
- 主插件不再读取 B站平台字幕，不提供字幕轨道选择。
- 百炼 API key 是生成新稿的前提；无 key 可读已有本地文稿缓存。
- DeepSeek 独立可选；无其 key 时仅采用说话人及完整 ASR 句子的基础规则。
- 打开侧栏、切换视频、读取缓存和刷新都不得自动发起付费云调用。

## 2. 功能与交互

| 功能 | 要求 |
| --- | --- |
| 原生侧栏 | 工具栏插件图标打开 Chrome/Edge Side Panel；不注入网页悬浮入口、不修改网页布局，宽度及开合由浏览器管理。 |
| 配置入口 | 右键工具栏图标 →“设置”，打开独立配置页，分别保存百炼与 DeepSeek 的密钥、模型；密钥不回显、不内置。 |
| 主动转写 | 点击“转写音频”并确认原始音频上传及收费提示后，自动依次完成转写与发言人推断；显示下载、上传、提交及等待等进度，提供取消。 |
| 基础稿 | ASR 成功后立即按 speaker 硬边界和完整句子生成基础段落，无需 DeepSeek。 |
| 时间跳转 | 点击正文句子跳到该完整 ASR 句的起点并开始播放；点击段落时间戳只跳转，保留播放/暂停状态；拖选复制不触发跳转。 |
| 高亮与跟随 | 播放及进度拖动更新当前 ASR 句及所属段落高亮；手动滚动或选字暂停跟随，可恢复，高亮仍更新。 |
| 人物信息 | 转写完成后自动结合标题、简介、UP主公开资料及**完整转写**推测说话人身份；name 优先为人名或账号名，没有具体名称时才使用“主持人/嘉宾”等角色；姓名必须在标题、简介或转写原文中出现，且同一具体姓名只分配给一个 speaker。证据不足显示未知发言人。推断失败不影响已生成稿件，可手动“推断发言人”重试。speaker ID 不等于真实身份。 |
| 保存与导出 | 本地保存原始 ASR、标准化句子、段落及偏好，支持 Markdown 导出；刷新只重新读取本地结果。 |

## 3. ASR 主流程与数据契约

主编排位于 [app.js](../extension/app.js)：

`读取原始 audio → transcribeAudio → normalizeTranscript → paragraphize`

### 原始音频与百炼

- 通过当前页面上下文获得原始 M4A 音频，直接下载并上传百炼，不转码、不先提取短片段作为正式输入。
- 默认模型为 `qwen-audio-3.1-asr-flash-filetrans`，提交异步转写并启用说话人分离；当前选择 `channel_id: [0]`。
- 保存已提交的 task ID，再轮询状态、获取原始结果。只有用户主动操作才能提交或恢复云任务。
- 原始音频的声道选择可能影响结果，不能承诺不同声道或再次识别得到相同句子数及 speaker 数。

### 标准化

[normalizeTranscript](../extension/transcript.js) 读取百炼 `transcripts[].sentences`，保留句子原文、毫秒起止时间、speaker ID 及 words；按时间排序后生成连续内部句子 ID。

- ASR 句子是不可拆分的基本单元，不把 words 强拆为阅读句。
- 缺失 speaker 作为未知说话人处理，不猜测真实身份。
- 时间来自 ASR，不由 DeepSeek 生成，也不凭字符长度插值逐字时间。
- ASR 的重复、口头语和识别错误原样保留。

## 4. 基础分段

- 按连续 speaker 回合处理，speaker 变化是硬边界，不允许跨说话人合段。
- 默认 `targetChars = 250`，在完整 ASR 句子之间选择接近目标的边界。
- 阅读目标为 200～300 字，不是强制区间：短提问、短说话回合可独立成段，完整长 ASR 句允许超过目标。
- **不采用硬字数上限**，不为长度拆句、不改正文。段落文本由关联句子原文直接拼接，时间及来源由句子推导。
- 不再提供大模型语义分段入口；分段完全由本地规则完成。

## 5. 缓存、取消与状态隔离

### 缓存键

- 文稿：`asr-document:v1:<bvid>:<cid>`，按视频及分 P 隔离，保存原始结果、句子、段落和保存时间。
- ASR 任务：`asr-task:v1:<bvid>:<cid>:<model>`，模型必须参与 task key；保存已提交的任务 ID 及完成的原始结果，不持久化上传凭据或临时资源 URL。
- DeepSeek：按句子内容、模型及提示词等请求身份缓存合法边界，不能只按视频名复用。
- 历史平台字幕缓存不视为 ASR 文稿缓存。

### 用户流程

打开视频 → 打开侧栏 → 读取对应本地文稿；无缓存时显示主动转写入口 → 配置百炼 → 确认付费及上传 → ASR → 基础稿 → 自动推断发言人 → 阅读、回看、导出。

- 无百炼 key：明确提示配置，不提交新任务；已有文稿可直接读。
- 无 DeepSeek key：基础稿仍完整可用，不能偷偷调用模型；自动推断会提示失败并保留稿件，可稍后配置后重试。
- 取消停止本地等待和后续步骤，已提交的云任务可能仍运行、仍收费，不宣称云端取消成功。
- 再次主动转写时，若同模型 task ID 已保存则续接，不重复下载上传或提交；云任务失败后重试可能创建新任务并再次收费。
- 刷新读取本地缓存，不清空稿件后自动转写；重新转写须再次主动确认。
- 切换标签页、视频或分 P 立即隔离旧稿、取消本地旧处理并忽略迟到结果；只控制当前标签页的视频。
- 网络、鉴权、无有效语音及缓存读取失败分别给出可操作提示；失败保留可读原稿和可续接任务。

## 6. 呈现与工程模块

侧栏采用白底、低干扰和段落留白；首行展示默认头像、匿名 speaker 及灰色起始时间，长视频使用 hh:mm:ss。正文独立滚动，当前句及段落逐级高亮。提供转写、推断发言人、取消、刷新读取、导出和恢复跟随，设置仍从工具栏右键菜单进入。

| 模块 | 职责 |
| --- | --- |
| 页面及播放通信 | 当前视频/分 P 上下文、原始音频地址、播放状态与 seek；不再获取平台字幕 |
| 百炼转写 | 原始 M4A 上传、异步任务提交及恢复、结果获取 |
| 逐字稿处理 | ASR 标准化、整句基础分段、说话人边界及时间映射 |
| 人物与面板 | 匿名 speaker 标签、默认头像、侧栏渲染、高亮、跟随及导出 |

旧字幕获取及原文校验模块可以作为存储工具或 legacy/offline 脚本保留，不能重新成为主插件的字幕读取路径。

## 7. 隐私与非目标

- 百炼仅在用户主动确认后接收原始音频；DeepSeek 仅在另行确认后接收文字、编号及上下文。
- 不读取或导出 B站 Cookie，不向页面桥接发送密钥；两家服务密钥仅本机扩展存储，CLI 私有配置与插件互不共享。
- 真实密钥、私有密钥文档及其公开链接、缓存、原始音视频、生成报告不得进入公开仓库或发行包。
- 不承诺 ASR 纠错、逐字时间精度、speaker 准确率或真实身份识别。
- 当前不做摘要、翻译、直播、其他平台及账号云同步。

## 8. 验收与已知验证范围

1. 主插件只走原始音频 ASR 路径，不读取平台字幕；无 ASR key 无法生成新稿，已有缓存仍可读。
2. 无用户主动确认不发起云调用；百炼与 DeepSeek 两个密钥分别配置，DeepSeek 可缺省。
3. 基础规则默认 250 字、完整句不可拆、speaker 硬边界；200～300 字是目标而非上限，长句不得因超过 350 字失败。
4. DeepSeek 仅返回合法 `paragraph_starts`，全文覆盖一次、顺序不变、正文不变、时间不变；语义完整性另需读稿评估。
5. task key 含模型；取消后可主动续接已提交 task，不重复提交；失败与切换不覆盖其他视频或现有稿件。
6. 点击句子播放，点击时间戳保留原播放状态；拖选复制、播放高亮、跟随暂停与恢复、Markdown 导出保持可用。
7. 覆盖无 key、无缓存、缓存恢复、下载/上传/提交/轮询失败、无有效语音、无效模型边界、取消和跨视频/分 P 切换；密钥不进入源码、发行包、桥接和日志。

当前已通过 111 项离线测试，测试仍会追加，以实际运行结果为准。约 29 分钟圆桌原始 M4A 的一次真实测试得到 168 个 ASR sentences、5 个 speaker、50 个基础段落；不据此保证其他声道或重复运行同结果，speaker 准确度未进行听校。

保留[旧 fixtures](../fixtures/README.md)及旧字幕/语义样本作为 legacy/offline 回归。历史 350 字上限、补标点结果与旧浏览器字幕联调仅说明旧算法行为，不能用于证明 0.4.0 ASR 全链路或说话人质量已验收。
