# B站逐字稿侧栏｜MVP PRD

## 1. 产品目标与范围

在 B 站视频页面一键获取当前用户可访问的中文字幕，整理为腾讯会议式的段落逐字稿，支持阅读、点击时间回看及播放高亮。重点支持中文自动字幕，保留原话，不以摘要替代原文。

- 平台：Chrome / Edge 桌面浏览器，仅 B 站普通视频页，支持分 P。
- 优先中文自动字幕，其次其他中文字幕，多中文轨道可切换。
- 无字幕时不自行转写音频，不绕过登录、付费或访问限制。

## 2. 功能

| 功能 | 要求 |
| --- | --- |
| 原生侧栏 | 点击浏览器右上角插件图标，打开 Chrome/Edge 原生 Side Panel 并自动获取字幕。移除网页悬浮入口与页面布局修改。左侧网页保留，侧栏宽度、开合和滚动由浏览器管理；正文独立滚动。 |
| 配置入口 | 右键浏览器工具栏插件图标 →“设置”，打开独立配置页，保存 LLM API key 和模型；不在侧栏内另做设置视图。 |
| 基础稿 | 不配置 AI 也可阅读。利用已有句末标点合并到约 200 字符，不硬切完整句子；无可靠句末边界时保留长段并提示。 |
| 智能分段 | 用户主动触发并确认上传字幕文字和编号至 DeepSeek，模型同时决定语义边界和补标点。处理中保留当前稿件，失败可重试或继续读原稿。 |
| 时间跳转 | 点击正文句子跳到该句首条关联字幕起点并开始播放；拖选文字不触发跳转。点击段落时间戳则保留原有播放/暂停状态。无标点基础稿按字幕片段定位，同一字幕内多句共享真实起点，不推算逐字时间。 |
| 播放高亮 | 播放和进度拖动后更新当前字幕片段及所属段落高亮，更新延迟目标不超过 1 秒。 |
| 滚动跟随 | 默认开启，手动滚动或选取正文后暂停自动跟随，提供恢复入口；高亮继续更新。 |
| 人物信息 | 默认通用圆形头像和“未标注”，暂不做识人或头像识别。 |
| 保存与导出 | 本地保存原字幕、基础稿、语义结果及偏好，支持 Markdown 导出；按视频、分 P、轨道和算法版本区分。 |

## 3. 智能分段算法

**模型决定语义边界，程序保证长度、完整性和时间映射。无需向量数据库或训练模型。**

### 输入输出

- 输入原始 `body` 数组，检查文字、起止时间、开始时间顺序；保留原始文字，内部按原顺序生成连续编号，不依赖 `sid`。
- 模型仅接收编号和文字、只读前后文，不接收原始时间。
- 模型返回 `{paragraphs:[{start_item,text}]}`；程序推导 `end_item`、`from`、`to`、`raw_text` 和最终 ID。
- 段落边界落在字幕条目之间；同一句话可能跨多条字幕，不直接把条目当作句子。

### 默认配置

| 参数 | 默认值 |
| --- | --- |
| 模型 API ID | `deepseek-flash`，非思考模式 |
| 每窗口 | 约 2,000 字符，以完整条目取数 |
| 前文 | 上一已提交段落，最多 300 字符 |
| 后文预览 | 约 300 字符，只读不输出 |
| 段数预算 | 窗口字符数 / 200，四舍五入，至少 1 |
| 阅读段落 | 理想 150～250 字符，含标点硬上限 350 |
| 重试 | 每个失败范围最多重试 2 次 |
| 跨文件并发 | 默认 3，允许 1～5；同文件顺序推进 |

### 流程与接缝

1. 构造带前后文的处理窗口，让模型同时分段和补标点。
2. 按结构、覆盖、正文、长度校验结果。
3. 非文件末尾只提交前 N−1 段；最后一段不提交，下一窗口从其首条字幕开始，补入后续内容重新判断。
4. 文件末尾提交全部段落。已提交前文只作为只读上下文，不重复输出。
5. 每个窗口提交后保存断点，完成后再做全文校验并导出。
6. 若模型只返回一段导致非末尾窗口无法推进，要求重分；达到重试上限后失败保存，不无限循环。

### 校验、重试与完整性

- 编号合法、严格递增，覆盖全部字幕恰好一次，无遗漏、重复和乱序。
- 仅允许常见句读和空白变化，不改正文、不删除重复和口头语，不纠正疑似识别错误。
- 数字小数点、百分号、日期、正负号、运算符、URL/email 等需要保留；不能仅用无差别删除全部标点后比较。
- 只有全文能唯一精确对齐条目边界时才修复起始编号，歧义结果拒绝。
- 正文错误或超长：只重试对应段落范围，保留其他通过段落，并将具体差异反馈给模型。
- JSON、超时、限流或无进展：重试本请求；限流和服务端错误有限退避；鉴权及配置错误直接停止。
- 不足 80 字符且非明显问句的段落标记检查，不无条件合并短段。
- 模型负责语义完整性，程序不按字符数硬截。无法兼顾完整表达与上限时保存失败供检查；单条字幕本身超 350 字符时不强拆条目。
- 时间来自原始字幕，不由模型生成；不推算逐字时间。补入标点仍映射到对应原始字幕，支持播放高亮。

### 工程能力

- 每个文件断点续跑，失败保留原文、已提交内容与失败状态。
- 请求缓存键包含输入、上下文、模型、提示词版本及参数；相同输入无需重复调用，不能仅按文件名缓存。
- CLI 跨文件并发，同内容任务去重；记录调用、缓存命中、失败、重试和 token 用量。
- 插件切换视频、分 P、轨道或刷新时停止旧任务，忽略迟到结果。已发出的单次后台请求可能继续完成，取消后不启动下一批。

## 4. 核心流程与状态

打开 B 站视频 → 点击工具栏插件图标 → 原生侧栏打开并获取中文字幕 → 显示基础稿 → 可选智能分段 → 阅读、跳转、高亮和导出。

切换标签页时立即清除旧稿并停止旧任务；非 B站视频页仍显示侧栏提示，不控制上一页视频。侧栏只向当前标签页发送播放命令，视频和分P切换后忽略旧消息。

- 加载中不显示上一视频内容；有缓存优先恢复对应结果。
- 成功读取轨道并确认无中文时才显示“没有可获取的中文字幕”。
- 能判定时区分需登录、访问限制；无法判定则提示获取失败并允许重试。
- 智能分段前告知上传范围；配置页本地保存密钥，插件不内置密钥。
- 处理中当前正文可读，提供取消和进度；失败保留原稿，提供重试。
- 刷新字幕恢复基础稿并清除对应语义结果，避免新字幕沿用旧整理稿。

## 5. 呈现

- 参考腾讯会议逐字稿结构：白底、低干扰、段落留白，无厚重卡片边框。
- 浏览器提供侧栏标题、原生关闭与宽度调整；内容区提供视频标题、刷新、导出及智能分段，不展示纪要或时间轴标签。LLM 设置从工具栏图标右键菜单进入。
- 段落首行：默认圆形头像、灰色“未标注”、灰色起始时间；长视频采用 hh:mm:ss。
- 正文建议 16px、行高 1.7～1.8、段间距 20～24px。
- 当前段落浅色底，当前字幕片段进一步高亮；保留原字幕核对入口与来源标注。

## 6. 四个业务模块

| 模块 | 职责 |
| --- | --- |
| 字幕获取 | B站上下文、轨道、原始 JSON、标准化和字幕缓存 |
| 文本分段 | 可替换的基础规则与语义批处理、校验和时间映射；请求、存储通过接口注入 |
| 人物信息 | 默认头像和标签，预留后续替换接口 |
| 面板与播放 | 渲染、跳转、高亮、跟随、设置和导出 |

后台请求适配、配置页及 CLI 为工程入口，不增加独立业务模块。人物识别仍不进入当前版本。

## 7. 隐私与非目标

- 原始字幕不变，默认本地保存；仅主动确认智能分段后向 DeepSeek 发送文字及编号，不发送 B站 Cookie 或原始时间。
- CLI 密钥使用本机私有配置，插件密钥使用本地扩展存储，不自动共享、不打入发行包。
- 自动字幕可能有识别错误，不承诺纠错或时间偏移修复。
- 不做语音转写、人物识别、摘要、翻译、非中文轨道、其他平台、直播、账号云同步和 SRT 导入。

## 8. 验收

1. 可一键获取中文自动字幕；视频、分P、轨道和缓存不串稿，旧任务不覆盖新内容。
2. 无 AI 配置可读基础稿；智能稿通过结构、全文覆盖、原文及 350 字符上限校验，段落由语义边界决定。
3. 长文件自动处理窗口接缝；局部错误有限重试；失败与取消保留可续跑断点及可读原稿。
4. 每段能追溯到原字幕、起止时间正确；补标点后播放高亮正常，点击时间保留播放状态。
5. 手动阅读不被拉回，支持恢复跟随；可以核对原文和导出 Markdown。
6. 覆盖无中文、获取失败、模型改字/漏字、超长、JSON/网络失败、取消及切换场景。
7. 密钥不进入源码、插件包、页面桥接和响应日志。
