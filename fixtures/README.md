# ASR 参考样例

这些文件用于离线回归和功能验证，不包含 API key、Cookie、临时鉴权地址或音频二进制。

- [圆桌 ASR 结果](./asr/BV1Gg411D7i7.json)：约 29 分钟原始双声道 M4A 的百炼结果，168 个完整句子、5 个匿名 speaker；移除了带签名的 `file_url`。用于 ASR 标准化、整句分段、人物处理和真实播放器联调，不触发付费调用，说话人准确率未经人工听校。
- [下载范围记录](./audio/download-metadata.json)及[解码验证](./audio/verification.json)：早期短音频获取实验的静态记录，背景见[音频验证说明](../docs/audio-experiment.md)。不作为当前完整原始 M4A 上传链路的端到端验收。

旧平台字幕与语义分段样例已移除。当前测试以 ASR 原句及直接构造的 cue fixture 验证，不依赖旧字幕解析、补标点或语义校验模块。识别错误、重复和口头语保留原样；单个样例不保证其他视频、声道、重复识别或网络环境得到相同结果。
